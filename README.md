# RoomSchedule — кто сейчас в аудитории СПбГМТУ

Консольная программа на C# (.NET 8). По номеру кабинета определяет, какое
занятие идёт в нём **прямо сейчас**: предмет, преподавателя и группу.

Данные берутся с официального расписания
[smtu.ru/ru/listschedule](https://www.smtu.ru/ru/listschedule/).
Сторонних библиотек нет — только стандартная библиотека .NET.

## Как это работает

1. Загружается страница `/ru/listschedule/`. С неё считываются:
   - текущий **день недели** и **тип недели** (верхняя/нижняя) — они напечатаны
     в заголовке: «Сегодня: 27 Мая 2026 года, Среда, нижняя неделя»;
   - карта аудиторий из встроенного JS-объекта `arRoom`
     (корпус → номер → внутренний `id` и `hex`).
2. По введённому номеру кабинета находится его `id`/`hex` и формируется ссылка
   `/viewschedule/room/{id}/{hex}/`.
3. Страница аудитории разбирается в табличном виде: по дням и парам с учётом
   типа недели.
4. Выбирается занятие, чьё время включает текущий момент, а тип недели совпадает
   с текущим (или помечен «обе недели»). Выводятся предмет, преподаватель, группа.

## Запуск

```bash
dotnet run -- 215                          # номер кабинета
dotnet run -- 215 --building="Корпус А"    # уточнить корпус (номера повторяются)
dotnet run -- 215 --dump                   # показать всё расписание кабинета
dotnet run -- 215 --at="27.05.2026 12:00"  # проверить на конкретный момент
dotnet run -- 215 --week=down              # принудительно задать тип недели (up/down)
```

Без аргументов программа спросит номер кабинета в консоли и дождётся нажатия
клавиши перед закрытием окна.

## Параметры

| Аргумент              | Назначение                                              |
|-----------------------|--------------------------------------------------------|
| `<номер>`             | Номер кабинета (например `215`, `404А`, `Спортзал`).   |
| `--building=<корпус>` | Ограничить поиск корпусом (`Корпус А`, `Корпус У`, …). |
| `--at=<дата/время>`   | Момент времени (по умолчанию — сейчас).                |
| `--week=up|down`      | Переопределить тип недели.                              |
| `--dump`              | Вывести всё расписание аудитории (для проверки).       |

## Сборка в Visual Studio

Нужен **.NET 8 SDK** (проверить: `dotnet --list-sdks` — должна быть строка `8.0.x`).

Если при запуске возникает ошибка вида
«Не удаётся найти RoomSchedule.exe» или
«Целевой процесс завершил работу без вызова события CoreCLR»:

1. Закройте Visual Studio.
2. Удалите папки `bin` и `obj` в каталоге проекта.
3. Откройте решение заново и выполните **Сборка → Пересобрать решение**.

Это пересоздаёт `obj/project.assets.json` (восстановление NuGet) и чистый
`bin`, после чего `.exe` запускается нормально.
